## About Coercitor

Coercitor is a browser-based utility built around XML generation and deployment for network engineering work. It is designed to reduce friction when handling repetitive ACI configuration tasks by helping you assemble XML files in a workflow that fits bulk operations.

It can be used to prepare XML for attachment in APIC or to send XML through a proxy server when your process calls for direct delivery. The tool is aimed at day-to-day configuration work where speed, consistency, and a web-first experience matter.

---

## Features

- Generates XML files for bulk configuration tasks
- Supports attaching XML output to APIC
- Can push XML directly through a proxy server
- Built for ACI-oriented network workflows
- Useful for recurring day-to-day configuration jobs
- Web-based interface for easier access from a browser
- Helps centralize XML preparation and deployment steps
